# AI Chatbot

An AI-powered chatbot built using Flask and Python that provides real-time conversational responses through an integrated AI API.

## Features
- Interactive chat interface
- Real-time AI-generated responses
- User-friendly web interface
- Flask-based backend
- Easy to deploy and customize

## Technologies Used
- Python
- Flask
- HTML
- CSS
- JavaScript
